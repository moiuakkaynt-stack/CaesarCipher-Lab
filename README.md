# Шифр Цезаря — варіант 6

Консольна програма шифрує та дешифрує український і латинський текст шифром Цезаря. Для кожного алфавіту задається власний зсув; регістр і розділові знаки зберігаються.

## Як зібрати
Відкрити `CaesarCipher.sln` у Visual Studio, обрати `Debug` та `x64`, виконати **Збірка → Зібрати рішення**.

## Як запустити

Після запуску програма послідовно запитує текст і величину зсуву.
Запустити без налагодження (`Ctrl+F5`).

## Приклад роботи
```text
Введіть український текст: Привіт, World!
Введіть зсув для українського алфавіту: 3
Введіть зсув для латинського алфавіту: 5
Результат: Тулдфх, Btwqi!
```

## Межові випадки
- зсув 1;
- зсув 32;
- зсув -1.

## Некоректний ввід
- порожній текст;
- нечисловий український або латинський зсув;
- нульовий або кратний довжині відповідного алфавіту зсув.

Програма працює в консольному режимі та використовує UTF-8 для українського тексту. та не змінює символи поза алфавітом.
